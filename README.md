# Student Task Manager

A simple and user-friendly task management application built with React Native and Expo.

## Features

- Add study tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by All, Pending, and Completed
- View task progress and statistics
- Clean, responsive user interface

## Tech Stack

- React Native
- JavaScript
- Expo
- AsyncStorage for local task persistence

## Getting Started

### Prerequisites
- Node.js
- npm
- Expo-compatible development environment

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Singanavenasahasra/student-task-manager.git
   ```

2. Navigate to the project folder:

   ```bash
   cd student-task-manager
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npx expo start
   ```

## Learning Outcomes

This project demonstrates basic React Native UI development, state management with React hooks, handling user interactions, and working with local storage.
